Variables locales et affectation

let reponse: i64 = 42;
let mut compteur: i64 = 0;
set compteur = compteur + 1;

let peut préciser mut, un type, une valeur initiale, ou les deux. set introduit une expression d’affectation. Une liaison immuable ne doit pas être modifiée ; les règles exactes sont vérifiées lors de l’analyse sémantique.

Retour et fin de boucle

  • return expression; et give expression; renvoient une valeur ; les formes sans expression terminent une procédure sans résultat.
  • break; sort de la boucle courante.
  • continue; passe au prochain cycle de la boucle courante.

Conditions et répétitions

if pret {
    traiter();
} elif en_attente {
    patienter();
} else {
    terminer();
}

while indice < 4 {
    set indice = indice + 1;
}

for valeur in 0..4 {
    utiliser(valeur);
}

La grammaire prévoit if/elif/else, while, loop et for nom in expression. Les exemples de bibliothèque parcourent des plages demi-ouvertes : 0..4 contient 0 à 3. Les types de séquences itérables disponibles restent dépendants de l’implémentation.

Match

match etat {
    Etat.Inactif => { afficher("arrêt"); },
    Etat.Pret => { afficher("prêt"); },
}

Les bras de la grammaire ont la forme expression => bloc-ou-expression, séparés par des virgules. La production formelle accepte des expressions de bras ; ne suppose pas la prise en charge de motifs plus riches sans confirmation dans l’analyseur et le compilateur.

Assertions, différé, unsafe et assembleur

  • assert(expression); vérifie une propriété à un point donné.
  • defer expression; ou defer { ... } exécute l’action en ordre LIFO à la sortie du bloc, y compris avant return, break et continue.
  • unsafe { ... } délimite un bloc qui exige des garanties manuelles.
  • asm "nop"; transmet un modèle d’instructions assembleur sans opérandes au compilateur C. La syntaxe asm(expression, ...); évalue les entrées une fois et émet une barrière compilateur avec clobber mémoire ; elle ne déclare pas de sorties.
Limites

unsafe ne déclenche pas d’analyse supplémentaire de sûreté mémoire. L’assembleur inline requiert un compilateur C compatible GNU ou Clang, et les instructions du modèle doivent convenir à l’architecture cible.
